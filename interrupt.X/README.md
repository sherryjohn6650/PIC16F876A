This project implements asynchronous serial communication (UART) with hardware-driven interrupt handling on a PIC microcontroller using the MPLAB XC8 compiler at 4 MHz. The main execution loop establishes a continuous background transmission routine that sends the character 'c' at 9600 baud via the hardware transmitter (TXREG). When an external character is received on the RX pin (TRISC=0x80), a receive interrupt triggers the isr() function, which captures the incoming character from RCREG, echoes it back via the custom transmit() function, and provides a quick visual acknowledgment by flashing all pins on PORTB for 200 milliseconds. It serves as a practical demonstration of hardware UART initialization, baud rate register configuration (SPBRG=25), and full-duplex interrupt-driven communication loop design.
