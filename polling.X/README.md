This project implements an asynchronous serial communication (UART) transceiver using polling-based reception on a PIC microcontroller with the MPLAB XC8 compiler at 4 MHz. Although labeled with an interrupt comment, all hardware interrupts are explicitly disabled (GIE=0, PEIE=0, RCIE=0), and data reception is instead handled by continuously polling the Receive Interrupt Flag (RCIF) within the main loop. In its background routine, the program constantly transmits the character 'c' at 9600 baud via TXREG with a 100ms delay; however, if an incoming character is detected on the RX pin (TRISC=0x80), the code immediately reads RCREG, echoes the character back using a custom transmit() function, and provides a 200ms visual status flash across all pins of PORTB. It provides an excellent educational contrast between interrupt-driven structures and software-driven polling mechanisms in embedded firmware systems.
