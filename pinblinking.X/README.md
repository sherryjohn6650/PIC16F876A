This project implements a synchronous multi-pin LED blinker on a PIC microcontroller using the MPLAB XC8 compiler at 4 MHz. Instead of toggling entire ports, the program handles GPIO manipulation at the individual bit level by configuring three specific pins—RC5, RB4, and RA2—as digital outputs and initializing them to a low state. Inside the infinite loop, the code concurrently switches these targeted pins between fully active (1) and inactive (0) states at precise one-second intervals using built-in delays. It serves as a foundational example of pin-specific bit addressing, synchronized multi-register coordination, and simple hardware timing integration for embedded C beginners.
