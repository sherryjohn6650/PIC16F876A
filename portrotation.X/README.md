This project implements a continuous Knight Rider style LED chaser (ping-pong animation) on a single port of a PIC microcontroller using the MPLAB XC8 compiler at 4 MHz. Configured with an external crystal oscillator, the program initializes PORTB as a digital output and drives an infinite loop containing two sequential loops with one-second delays. The first loop shifts an active-high bit forward from pin 0 up to pin 7 (1<<i), while the second loop cleanly reverses the direction by shifting the bit backward from pin 6 down to pin 0. This architecture prevents double-blink pauses at the turning points and serves as a classic, foundational demonstration of symmetric bi-directional bit-shifting and precise delay manipulation in embedded systems.
