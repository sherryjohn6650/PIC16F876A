This C program for a PIC microcontroller demonstrates basic digital I/O control and timing using the XC8 compiler. Operating at a 4MHz clock frequency, it configures all pins on PORTB and PORTC as digital outputs and continuously toggles their states at one-second intervals. PORTB alternates between a checkerboard bit pattern (0xAA and 0x55), while PORTC switches between high and low nibbles (0xF0 and 0x0F). It serves as a straightforward example of GPIO manipulation and delay functions, perfect for testing basic microcontroller operations or driving an alternating LED sequence.
