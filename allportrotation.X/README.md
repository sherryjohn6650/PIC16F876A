This project implements a multi-port sequential LED chaser pattern on a PIC microcontroller using the MPLAB XC8 compiler at 4 MHz. The program configures PORTA, PORTB, and PORTC as digital outputs and initialises them to a low state. Inside an infinite loop, it uses bitwise left-shifting operations combined with one-second delays to cascade a single active-high signal sequentially through the individual pins: first ascending through pins 0 to 6 on PORTA, then descending from pin 7 to 0 on PORTC, and finally descending from pin 7 to 0 on PORTB. It provides a clear, foundational demonstration of multi-register GPIO coordination, array-free iterative bitwise shifting, and precise hardware delay integration for embedded firmware developers.
