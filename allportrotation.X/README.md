This project implements a sequential LED chaser pattern across three ports (PORTA, PORTC, and PORTB) of a PIC microcontroller using the MPLAB XC8 compiler. Configured for a 4 MHz external crystal oscillator, the program initializes the pins as digital outputs and runs an infinite loop that shifts a single high bit across each port with a one-second delay between steps. It serves as a foundational example of basic GPIO manipulation, bit-shifting mechanics, and hardware configuration management (disabling the Watchdog Timer and Low-Voltage Programming).
