This project implements a 4-to-2 binary priority encoder simulation on a PIC microcontroller using the MPLAB XC8 compiler at 4 MHz. The program configures PORTB as a digital input to read individual activation lines and PORTC as a digital output to display the generated binary code. By continuously evaluating input pins RB1 through RB4 within an infinite loop, the nested conditional structure prioritizes the active line and translates it into a specific 2-bit binary representation (00, 01, 10, or 11) on PORTC. It serves as a practical demonstration of mapping combinational digital logic and handling signal prioritization in embedded systems.
