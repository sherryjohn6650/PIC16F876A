This C program for PIC microcontrollers demonstrates basic digital input/output control using the XC8 compiler. It configures PORTB as an input and PORTC as an output, operating on a 4MHz oscillator. The main loop continuously polls pin RB2 (acting as a switch or button input); when a high signal is detected, it triggers a blinking sequence that toggles all pins on PORTC high and low with a one-second delay.
