This project implements a hardware 2-to-4 binary line decoder simulation on a PIC microcontroller using the MPLAB XC8 compiler at 4 MHz. The program configures PORTB as a digital input to read binary select lines and PORTC as a digital output for the decoded channels. By continuously polling input pins RB1 and RB2 inside an infinite loop, the code evaluates all four possible binary input combinations (00, 01, 10, 11) and routes a single active-high signal to a dedicated output pin on PORTC (0x01, 0x02, 0x04, or 0x08). It serves as an essential example of implementing combinational digital logic and multi-condition branch handling in embedded C.
