This C program for a PIC microcontroller demonstrates basic digital I/O control by triggering different LED sequences on PORTB based on switch inputs on PORTA. After configuring the analog pins to digital mode, the main loop continuously polls pins RA0 and RA1. A high signal on RA0 activates a sequential 8-bit LED chaser effect, while a high signal on RA1 toggles an alternating blinking pattern between the upper and lower nibbles (4 bits) of the port. Both lighting sequences include internal state-change checks during their 1-second delay cycles, allowing the loops to immediately interrupt and clear the outputs if the active button is released.
