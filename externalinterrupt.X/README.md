This project implements hardware-driven asynchronous multitasking via an External Interrupt Service Routine (ISR) on a PIC microcontroller using the MPLAB XC8 compiler at 4 MHz. The main program execution loop maintains a steady background routine that blinks the upper bits of PORTB (0xF0 to 0x00) at 1-second intervals. When a hardware interrupt signal triggers on the RB0/INT pin (TRISB=0x01), the microcontroller temporarily halts this background task to execute the isr() function. The ISR clears the interrupt flag (INTF=0) and runs a dedicated 5-cycle sequential LED chaser pattern back and forth across PORTC before re-enabling global interrupts (GIE=1) and seamlessly returning execution back to the background blinking loop.
