This project implements a button-controlled, limited-cycle LED blinking system for PIC microcontrollers using the MPLAB XC8 compiler at 4 MHz. The program configures PORTB as a digital input and PORTC as a digital output, continuously monitoring the state of the RB1 pin. When a high signal (button press) is detected on RB1, the system blinks all LEDs connected to PORTC at one-second intervals while tracking the cycles with an internal counter. Once the LEDs blink exactly five times, an integrated lock-out condition permanently deactivates PORTC, demonstrating practical applications of input polling, conditional loops, and software-enforced hardware constraints.
