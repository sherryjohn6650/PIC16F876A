This project implements a push-button toggle switch system for PIC microcontrollers using the MPLAB XC8 compiler at 4 MHz. The program configures PORTB as a digital input and PORTC as a digital output while monitoring the RB1 pin for user input. By utilizing a blocking while(RB1==1); loop, it incorporates a hardware release-detection mechanism that waits until the button is fully released before flipping an internal tracking variable (flag). Each registered press-and-release action alternates the state of PORTC between fully active (0xFF) and fully inactive (0x00), serving as a foundational example of software-based edge detection and state toggle logic in embedded C.
