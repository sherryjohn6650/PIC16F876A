This C program for a PIC microcontroller demonstrates how to configure and handle external hardware interrupts using the XC8 compiler. Operating at a 4 MHz clock frequency, the code initializes pin RC2 as a digital output and enables the external interrupt feature. When a hardware event triggers the external interrupt pin, the Interrupt Service Routine (ISR) immediately executes, clears the interrupt flag, and toggles the state of the RC2 pin. This non-blocking approach is a foundational technique used to efficiently detect external signals—such as button presses or sensor triggers—without pausing or delaying the main program loop.
