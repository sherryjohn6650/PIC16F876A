This project implements a synchronous multi-port LED blinker on a PIC microcontroller using the MPLAB XC8 compiler at 4 MHz. The program configures PORTA, PORTB, and PORTC entirely as digital outputs and initializes them to a low state. Inside an infinite loop, the code simultaneously toggles all pins across all three registers between fully active (0xFF) and fully inactive (0x00) states using integrated one-second delays (__delay_ms(1000)). It serves as a foundational example of basic GPIO master clearing, simultaneous multi-port register assignment, and precise hardware delay generation for beginners exploring embedded systems.
