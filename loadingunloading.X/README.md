This project implements a progressive bar-graph style LED accumulator and dissipator pattern on a PIC microcontroller using the MPLAB XC8 compiler at 4 MHz. The program configures PORTB as a digital output and manages its states within an infinite loop using iterative bitwise operations and one-second delays. The first loop sequentially turns on each pin from pin 0 to pin 7 using a bitwise OR operation (PORTB | (1<<i)), filling up the port like a progress bar, while the second loop sequentially clears each pin from pin 7 down to pin 0 using a bitwise AND-NOT operation (PORTB & ~(1<<i)). It serves as a clear, foundational example of masking, accumulative state preservation, and precise hardware delay implementation for embedded C developers.
